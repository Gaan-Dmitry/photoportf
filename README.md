# Профессиональная фоторетушь

Веб-приложение для приема заявок на профессиональную ретушь фотографий, а также отображения портфолио работ с эффектом "до/после".

## Запуск проекта локально

Для запуска проекта на вашем компьютере должны быть установлены [Node.js](https://nodejs.org/) и npm.

1. **Установка зависимостей:**
   Откройте терминал в папке проекта и выполните команду:
   ```bash
   npm install
   ```

2. **Запуск сервера:**
   После установки зависимостей запустите сервер командой:
   ```bash
   node server.js
   ```

3. **Просмотр:**
   Откройте браузер и перейдите по адресу:
   [http://localhost:3000](http://localhost:3000)

## Развертывание (Деплой) и GitHub Pages

**Важное замечание:** Этот проект использует **Node.js** (для маршрутизации, обработки форм и админ-панели) и **SQLite** (для хранения заявок и элементов портфолио).

Из-за этого проект **невозможно** разместить на **GitHub Pages**, так как GitHub Pages поддерживает только статические сайты (состоящие исключительно из HTML, CSS и клиентского JavaScript), и не позволяет запускать серверный код на Node.js или работать с базами данных.

Для публикации этого сайта в интернете вам потребуется использовать сервисы, поддерживающие запуск Node.js приложений. Вот несколько популярных бесплатных или недорогих вариантов:

- **[Render](https://render.com/)** - отличный вариант для бесплатного хостинга Node.js проектов.
- **[Railway](https://railway.app/)** - прост в настройке, поддерживает деплой прямо из GitHub.
- **[Fly.io](https://fly.io/)** - еще один хороший сервис для развертывания fullstack приложений.
- **VPS хостинг** (например, Timeweb, Beget, DigitalOcean) - аренда виртуального сервера для полного контроля, где вы сами устанавливаете Node.js и запускаете проект.
