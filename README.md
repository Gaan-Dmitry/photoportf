## О проекте

Этот проект представляет собой простую отправную точку для развития лабораторных идей. Работает на нативном PHP и SQLite.

## Запуск локально

1. Убедитесь, что установлен PHP (>= 7.4) с расширением SQLite.
2. В корневой директории выполните:
   ```bash
   php -S localhost:8000 router.php
   ```
3. Откройте браузер и перейдите по адресу: [http://localhost:8000](http://localhost:8000)
